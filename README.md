# Save System

Save/load system for Unity 6: key-value data, automatic saving of scene objects, slots with metadata, crash-safe files with backups, optional compression and encryption, version migrations.

<a name="english"></a>
# English

**Requirements:** Unity 6000.0+

## Installation

**Window > Package Manager > + > Install package from git URL…**

```
https://github.com/Atthree/SaveSystem.git
```

To lock a version: `…/SaveSystem.git#v0.1.0`
